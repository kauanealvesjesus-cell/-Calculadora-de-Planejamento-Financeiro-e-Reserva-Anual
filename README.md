# -Calculadora-de-Planejamento-Financeiro-e-Reserva-Anual
Este projeto foi desenvolvido como atividade escolar do 1º ano do Ensino Médio.  O objetivo é criar uma calculadora de planejamento financeiro que mostra como uma reserva de dinheiro pode crescer ao longo dos anos.  A calculadora utiliza valores de salário, reserva anual e rendimento para apresentar uma simulação financeira.
